# 🌐 Ralph Dagondon — Portfolio Website

This is my personal portfolio website, built to showcase my **projects**, **experience**, and **skills** as a Cyber Security student and Full-Stack developer.

## ✨ Features

- Responsive design built with **Next.js** + **TailwindCSS**
- **Dark/Light theme toggle** powered by `next-themes`
- **Animated sections** with `framer-motion`
- Interactive project and experience cards
- **Technologies filter menu** (desktop + mobile hamburger)
- Contact section with quick links (Email, GitHub, LinkedIn)

## 🛠️ Tech Stack

- **Frontend Framework:** Next.js (React, TypeScript)
- **Styling:** TailwindCSS, Shadcn/UI components
- **Animations:** Framer Motion
- **Icons:** Lucide-react, React Icons
- **Deployment:** Docker, Personal Linux Server

## 📂 Project Structure

```bash
src/
├── app/ # Next.js 15 app router
│ ├── components/ # Reusable components (Navbar, Hero, etc.)
│ └── page.tsx # Main entry
├── components/ # Shared UI components
├── styles/ # Global styles (globals.css, themes)
└── public/ # Static assets (icons, images, resume)
```
